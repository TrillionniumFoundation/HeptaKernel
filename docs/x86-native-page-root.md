# Fixed metadata identity admission before writer lease

Experimental HOLD, based on #250 exact c68b545c89a898ac14101598a5b3c1e71638d23d. The fixed two-CPU writer lease was previously derived from live FS/GS but did not inspect the actual leaf translating the metadata virtual page before the first CAS. This candidate adds HIA f8: check the three fixed live low-tree links (only accessed bit may vary), then require the slab first page PTE to be the expected identity frame, present/writable and otherwise exact modulo hardware A/D bits. This preflight precedes both explicit lease operations and ordinary lifecycle lease acquisition. Inherited bounds, upper/low alias scan, CAS generations and all failure semantics are retained.

In the independent observer the retiring owner, in each CPU direction, copies the actual metadata page to separate boot memory, changes the real slab PTE, invalidates the local translation and writes a marker through the slab VA that is independently observed at the alternate physical page. A native lease acquisition must refuse with 6 and leave the alternate lease unchanged. The original mapping is restored; the original lease, marker and retiring ledger are verified. Deleting only the new conditional guard must actually acquire the lease in the alternate page, while the original lease remains unchanged. Both PC/Q35, both CPU directions: 8 new cases, plus all 44 inherited focused cases, local 52/52 PASS. This checks a fixed metadata leaf under the existing trusted identity access to the page-table pages. It does not establish immutable metadata, physical access independent of virtual translation, protection against a concurrent noncooperative writer after preflight, stale remote translation, CR3 changes, NMI/reentrant same-CPU lease release, general topology or DMA authority. The observer's deliberate remap is performed while the peer waits. All 660 inherited cases and 52 focused cases are planned for separate CI reexecution. Production lock, original full Linux acceptance and all historical failures remain unchanged.

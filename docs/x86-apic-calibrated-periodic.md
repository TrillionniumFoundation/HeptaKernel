# Experimental native calibrated periodic xAPIC

Based on #189 exact 1e7300a6fb7c6a12cb2df18c0b7ec39779c19e52. All prior #188/#189 sources, workflows and tests remain unchanged. New isolated HIA exports f0/f1 reuse real masked calibration, f2 derives a count from the two measured native countdown deltas, f3 calls f2 and a private native arm helper, f4 handles EOI, f5 validates the expected active count and masks/stops. Two reference windows are 12000/24000 PIT ticks. For samples s,l, require nonzero values and 3s <= 2l <= 5s; derive round((2s+l)/4) for 12000 and round((2s+l)/2) for 24000, with widened arithmetic and bounds [1024,2^31-1]. This is a bounded fixture, not a general clock estimator. No fixed APIC initial count in the private arm helper.

Independent oracle checks widened scalar arithmetic on boundary/random inputs by native f2 calls in an isolated host process; no host privilege action. PC/Q35 fixture measures actual calibration, independently computes exact count and reads back actual timer configuration, checks actual periodic interrupts during an independent PIT window, rejects bad calibration and wrong stop count, then verifies a quiet PIT window after native stop. A count-store deletion specifically bound to the private HIA arm helper must leave the initial count zero and return the exact failure. Raw samples and observed IRQ counts retained. Eight planned QEMU cases; no new PASS before independent exact-head CI.

Resource/clock authority, portable calibrated timekeeping, periodic scheduler, native interrupt entry/return, general timer restore and Linux full acceptance remain open. Original 17 gates and 422 syscall rows unchanged.

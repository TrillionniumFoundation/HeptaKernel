# Fixed cooperative page writer lease before page transfer

Experimental HOLD, based on #249 exact cf01e56a943bc1402a437c21c489ba6017ab5e18. Adds native HIA generation-bound CAS writer lease to the fixed two-CPU, boot-reserved identity-map experiment. The aligned reserved slab+3576 word is separate from the existing ledger (slab+3584), initially generation 1/free (4). Live xAPIC identity and FS/GS binding plus bounded slab/arena and live CR3 layout/disjoint preflight precede the first lease CAS. All previous revoke/ACK/recycle operations acquire the same lease before the entire old upper/low alias scan, keep it through mutation and release by exact owner/generation CAS; busy returns 11 without running the old mutation path. Explicit cooperative acquisition and release use operations 3/4 and the expected generation; stale or foreign release returns 9. Failed lease release is partial 10, not success. No counter wrap is allowed.

The independent PC/Q35 observer forces each CPU in turn to be the retiring owner while the other actually holds the native lease. The owner attempts foreign release and real revoke, verifies status 11, unchanged live identity PTE, retiring ledger and both page endpoints. The peer releases, reacquires at the next generation, rejects old release against the live later lease, releases correctly, and the original end-to-end revoke, two actual fault/ACK observations, scrub and new owner publication complete. Independent compiled guard-bypass mutations actually clear the PTE while the peer's lease remains held; both directions detected. All 36 previous focused cases are rerun with the new native implementation and 8 new cases, local exact compiler 44/44. r1 already passed 44 but preflight for slab/table disjointness was after first lease write; r2 added preflight but extra blank source line caused native compiler exit 2; r3 removed blank line, retained strengthened replay and final free checks, reran 44/44. This is a cooperative lease for the new fixed lifecycle path, not a proof that arbitrary page writers, direct stores, other address spaces, DMA, NMI, or concurrent CR3 changes obey it. It does not confer a general trustworthy root or page authority. The explicit lease is a primitive, not a general page-table editing API.

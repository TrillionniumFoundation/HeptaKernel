# Native HIA bounded COW reference-count transitions

`src/cow_refcount.hepta` is **genuine fixed HIA Core v8 source**, compiled with the pinned `selfhost_elf` backend into freestanding x86-64 machine code. It updates one byte in a caller-owned, exactly 4096-byte reference-count array with an exact-old check. This is a bounded, sequential *single-owner* transition for preparing COW bookkeeping; it does not implement Linux COW.

Public ABI: `f0(request:readbuf,receipt:mutbuf,counts:mutbuf) -> u32`. The request is exactly 16 bytes: 16-bit little-endian slot (0..4095), one-byte action, one-byte expected old count, then 12 zero reserved bytes. Action 1 shares an owned page (count 1..254, increment); action 2 detaches an existing sharer (count >=2, decrement); action 3 releases the final reference (count =1, set zero). The receipt is exactly 16 bytes. On success, it becomes eight zero bytes followed by the new count byte and seven zero bytes; exactly one table byte changes. On any failure the receipt and table must remain unchanged. Return codes: 1 invalid receipt length; 2 invalid request; 3 invalid count-table length; 8 nonzero reserved request bytes; 4 out-of-range slot; 5 invalid action; 7 stale expected count; 6 underflow/overflow/invalid transition.

The independent native differential test enumerates slot/action/count boundaries and randomized malformed capabilities, checks every byte and both canaries, and exercises the first and last table entries with real OS PROT_NONE guard pages. A distinct HIA no-op program falsely reports success; the same oracle must detect it. The native object is also recompiled with empty PATH and compared byte for byte.

**Safety boundary:** A raw 4 KiB buffer is not an authenticated frame identity or a page ownership authority. Eight-bit counters cap share count at 255; neither byte stores nor the old-value check are atomic. No SMP consistency, reference-count saturation policy for full Linux, physical frame lease/pin, PTE replacement, write-protect fault, page copy, TLB synchronization, interrupt exclusion or DMA protection is provided. The caller must ensure disjoint buffers, exclusive access, no asynchronous writers, and proper ordering of any physical page copy before a detach transition. This does not lower or implement HIA privileged instructions. Linux's full 17 gates and 422 syscall rows remain HOLD.

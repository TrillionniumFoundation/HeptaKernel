# Native terminal dispatch EOI composition — experimental HOLD

Based on exact dispatch-compose candidate 0b37917f087a28fdf450ca0a294277bfadc637d8. No production lock or main change. The entire existing native dispatch function and its callees are preserved modulo the private export rename, and the existing timer EOI function is included byte-for-byte except its function name. The wrapper snapshots IA32_APIC_BASE before dispatch; the checked EOI routine verifies the live base, active vector and absence of a higher in-service vector, writes EOI, and independently reads back the ISR bit.

The same native export now performs EOI only after a dispatch commit (0) or an admitted no-switch (64). Preflight refusal (65/66), successful compensation (69), incomplete compensation (67) and other partial failure (70) propagate without EOI. An EOI refusal or failed readback after a commit or stay returns 71; the caller must fail-stop, must not restore a task or retry a committed dispatch, and must not attempt to roll back published owner state. This candidate does not claim that returning 71 alone guarantees a production fail-stop.

The new independent assembly observer checks actual ISR before retry and after commit/stay, all slots, owner and ready words, task progress and actual IRQ returns. It no longer repeats the old-owner publication after EOI because that routine requires a live ISR; the exact original observer and all inherited tests remain. The supervisor's final return remains a separate checked EOI call. Independent mutations inject stale owner and stale ready expected generation, bypass EOI, or remove the EOI write while retaining readback. The last mutation must leave a committed dispatch unchanged and emit E/35 without task return. Y/35 catches a falsely successful EOI with active ISR. V/35 and Z/35 retain the recovery/partial controls and require the live ISR bit.

This is single BSP, non-nested, caller-owned memory, not general multi-word atomicity or resource authority, not SMP, and not complete Linux ABI. Native terminal trap/return integration, synchronous sleep/wake, native HLT and general CPU handling remain open. Original 17 HOLD gates, 422 syscall obligations, 3s/5s/60s budgets and all historical failures remain. No original tests are removed or weakened.

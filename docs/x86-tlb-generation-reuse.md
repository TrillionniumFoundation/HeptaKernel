# Experimental three-generation TLB and retired backing isolation

Parent #185 exact f8982e7d36f19c9ebb141bc168381a6da01ce901, independently tested on both PC and Q35 (10/10). Original source, test, workflow and stronger post-IRET stale obligation are retained unchanged.

The new native HIA subject alternates two fixed backing pages through generations 2, 3, 4. f3 publishes the leaf; f0 sends a directed interrupt; f2 invalidates on AP; f1 completes EOI; f4 binds observed value to generation parity and changes 2g to 2g+1. New BSP-only f5 checks nonzero aligned bounded slot and generation, live xAPIC identity, and atomically changes exactly 2g+1 to 2g+2. No advance from pending, wrap, duplicate or wrong CPU is admitted. Independent AP reads after native invalidation and IRET, tests stale/future generations, wrong-CPU advance and duplicate completion. BSP checks every state transition and actual mapping. It writes a decoy to retired physical backing only after AP ACK and requires a subsequent actual AP virtual read to retain the live value. Decoy is restored before page is reused as next mapping.

PC/Q35 controls suppress second-round ACK and separately delete ACK or generation-advance CAS. Original #185 ten scenarios remain independently runnable. New eight cases planned, no PASS before exact CI. Fixed two-vCPU test with observer-provided slot/backing authority, bootstrap, interrupt entry/return and transport. Not an allocator, general reclamation, arbitrary cohort or Linux closure. No changes to main, production lock, 17 HOLD gates or 422 syscall obligations.

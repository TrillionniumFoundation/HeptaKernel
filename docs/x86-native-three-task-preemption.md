# Experimental native three-task preemption (HOLD)

Exact parent: 09c593f17656c9e7bb18d2e5c3549386a1e3ef30 (#206). The production compiler lock, main, original acceptance and inherited tests are unchanged.

The raw IDT gate is the independently qualified HIA IRQ entry. Three fixed, nonoverlapping CPL0 stacks contain distinct patterns for all 15 GPRs. A caller-owned, NON-HIA SysV observer validates the captured RIP, RSP, frame address and original registers, and invokes the actual HIA ready exchange, frame handoff and owner publication. The actual selected index determines the consumed frame and the native gate returns using IRETQ. The observer contains no IRET instruction. The APIC periodic timer uses a fixed count for the experiment; this is not a new clock calibration result.

The owner publication uses low two bits for task identity 0..2 and a nonwrapping 62-bit generation. It retains live BSP/APIC ISR guards and parked/empty slot identity CAS checks from the restricted predecessor. It rejects invalid old/new task IDs, unchanged task ID, overflow and stale generation. The new owner CAS is separate from the ready CAS and frame-slot operations.

In each positive guest there are 13 actual delivered APIC interrupts and 12 real task switches. At tick 4 the native publisher clears the parked task 2 ready bit; at tick 7 it restores it. The actual selected sequence is 1,2,0,1,0,1,2,0,1,2,0,1. Independent checks require all 15 GPRs, progress per departure, 5/5/3 captured task departures, exact ready generation 14, owner generation 12 / task 1, four owner admission refusals, 12 stale owner replay refusals, all frame slots and adjacent canaries. On the thirteenth tick the independent observer returns to the supervisor solely to end the test and stop the native timer.

Local exact HIA qualification: 18/18 QEMU cases on PC/Q35, including short/long positive and seven separate wrong-source or instruction-deletion controls per platform. Native machine code and linked image text are checked independently; source mutations must compile and change text. The seven controls are missing requeue, missing ready update, owner CAS deletion, park CAS deletion, consume CAS deletion, wrong r15 save, and missing raw IRETQ (exact UD sentinel). The test preserves FAIL before any assertion, records each result and does not retry to mask failure.

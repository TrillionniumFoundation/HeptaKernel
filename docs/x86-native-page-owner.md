# Native live CPU-bound page claim and non-reusable retirement (HOLD)

This independent boot-reserved arena experiment implements a per-page atomic state machine, not the original single-owner bitmap allocator. The 64-entry ledger at offset 3584 in the boot-provisioned scheduler root derives all entry addresses from the actual IA32_FS_BASE and each aligned target page in the 64-page contiguous physical identity arena immediately following the slab. It checks root and arena extent in the first 2 MiB, live xAPIC enabled mode and ID 0 or 1, and GS matching the derived CPU descriptor before any ledger access. The owner is derived from that live identity, not provided by the caller.

An exact generation word encodes free as generation*1024, owned as generation*1024 | live ID+1, retired as the owned word with bit 9 set. A single native LOCK CMPXCHGQ commits each claim or retirement. Only the exact current owner at the exact generation can retire a page. A retired page cannot be claimed or retired again. No reclaim/free operation is exposed; a later TLB/cohort proof must precede actual reuse. All malformed, stale, foreign and retired operations refuse without changing the ledger.

PC/Q35 local 10/10 actual hardware-emulation scenarios: both vCPUs begin a shared-page claim after an independent barrier; exactly one claims, the loser is refused on its actual attempted retirement while the owner is still live, then the owner retires and both stale replays fail. Two ordered controls exercise both possible live owner directions independently. Each CPU separately claims and writes the first and final word of a distinct real physical page, retires it, and still completes both original guarded IRQ cycles. BSP additionally claims the last page at the maximum valid generation, writes/readbacks, retires and cannot reclaim it. Both CPUs test wrong GS, out-of-range, unaligned, zero/overflow generation, invalid operation and stale generation. Independent final checks cover untouched ledger entries and exact markers; the linked arena and live paging structure symbols are disjoint. Two separately compiled CAS-identity mutants exhibit both CPUs reporting a false claim with free ledger unchanged, or a false retirement with the actual owned word unchanged. The r1 claim mutant printed two N markers due to two observers simultaneously exiting; the original failure is retained locally. r2 elects BSP as the reporting CPU only after both result words and the exact unchanged ledger are checked, with native objects unchanged. r3/r4 extend boundary and ordered controls; r4 verifies all native case/object bytes identical to r3. Original compiler, raw entry, guard and callback object bytes retained.

This is an atomic two-CPU bounded arena ownership/retirement mechanism under boot-reserved physical identity mappings and a trusted stable FS root. It is not a production allocator, root provisioning/lifetime guarantee, immutable page-table writer exclusion, hardware prevention of arbitrary privileged writes, arbitrary CPU topology, TLB cohort reclaim, migration or full Linux acceptance. 518 inherited and 10 new hardware scenarios are required in the independent workflow; the 17 HOLD gates, 422 syscall obligations, original timing budgets and historical failures remain unchanged.

# Restricted native composed frame handoff and rollback

Parent #197 exact 1c84826b60e7a06385b50b229326771280786e6f, both independent specialized runs 18/18 plus 3477 arithmetic. All old files and their workflow remain unchanged.

New genuine HIA f2 composes existing native park and consume functions, preflights both complete fixed-size stack intervals, disallows overlapping stacks, aliased slots, slots inside either stack, misalignment and invalid frame extents. It parks the departing frame then consumes the exact destination. If consumption refuses, it consumes its own parked pointer to roll back; rollback failure returns a separate fatal status. Neither a stale nor an absent target authorizes publishing the next active task. The independent observer keeps active publication after both real slot readbacks. On success it exercises four real switches, each preceded by slot-alias rejection and a well-shaped stale target rollback. A missing destination is independently injected on the first switch. Separate deleted park/consume CAS cases must expose missing effects before active publication. Existing original controls remain in the parent and in the new observer for legacy park/consume variants.

This is a restricted single-BSP, non-nested IRQ composition. Bounds and frame pointers remain caller-owned; two CAS operations and compensating rollback do not constitute a linearizable multiword transaction for arbitrary concurrent writers. On error the experiment fail-stops; the prior scheduler tick and progress bookkeeping are not rolled back. No general scheduler, resource authority, FPU or arbitrary interrupt/exception proof. New 24 hardware cases planned, no claim of pass until exact CI. Original 17 HOLD gates and 422 syscall obligations remain.

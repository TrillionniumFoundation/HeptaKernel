# Experimental native delivered tick and two-tick quantum decision
Parent #192 exact 14378d6ce10a2cdc54335472048ef0d79d4391f3, PR 45520235294 and push 45520225888 both independently pass ten PC/Q35 cases. All parent files remain unchanged.

New native f12 requires aligned nonzero bounded slot, no counter wrap, exact enabled xAPIC MSR, BSP identity, live timer ISR bit and unmasked periodic LVT. The CAS changes exact expected tick to next tick, with a fence; return 1 on every even delivered tick, 0 on odd tick. Inactive IRQ, invalid shape, stale and overflow refuse. The assembly observer counts actual interrupts independently, invokes f12 inside the IRQ, tests misalignment, overflow and stale refusal, checks the native counter and quantum decisions, and separately accounts for masked pending interrupts during teardown. Outside-ISR rejection and neighboring canaries are checked. Mutating only f12 CAS must leave the native counter zero despite actual interrupts. The original five cases are retained in this new experiment plus CAS deletion; original #192 files and gates unchanged. All new 12 cases pending independent CI. Caller supplies slot and expected prior, no authority or same-IRQ duplicate-proof claim. Delivered tick count is not elapsed time, and quantum decisions do not constitute a scheduler or context switch. Native IRQ entry and IRETQ remain open. No Linux gate, main or production lock changes.

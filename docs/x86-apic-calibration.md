# Experimental masked xAPIC clock calibration

Descendant of #188 exact d80d87ee77966cde84ab3bb5f36257345ea1ac68; original 30-case periodic tests remain unchanged. Native HIA arms masked one-shot APIC countdown with divider 16 and maximum initial count, validates live state, samples actual current count and stops with readback. Independent assembly measures two PIT channel-2 mode-0 windows (12000 and 24000 ticks), brackets native count by direct MMIO and records raw counts plus inferred divided-clock frequencies. The doubled interval must yield a bounded proportional count. Native negative controls cover bad base/stale MSR and independent divider/initial count/stop store deletion. No production clock authority, calibrated scheduler or native teardown claimed. No Linux gates changed.

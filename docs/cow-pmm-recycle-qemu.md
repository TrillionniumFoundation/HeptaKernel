# Native HIA COW guarded abort to PMM reuse on QEMU

After a real CPL0 #PF, unchanged locked HIA machine code copies the 4 KiB page and adjusts both reference counts. A deliberately stale HIA PTE swap refuses publication; HIA guarded abort inspects the actual active PTE, zeros the unpublished private frame, and restores the reference counts. A second real HIA PMM call frees the destination physical frame, and a third reissues it at the same physical address (0x602000). The independent hardware bridge checks the full 4 KiB source and destination pages, the complete 4 KiB refcount table, the actual PTE and the complete 8192-byte PMM state.

The positive recycle case checks PMM free count 14 to 15 and bitmap 7 to 3 after free, the exact reallocated physical address, and all PMM bytes against a pre-release snapshot after reallocation. A negative double-free case demands original HIA status 7 plus all 8192 PMM bytes unchanged after a second attempted release. Both execute on PC 32 MiB and Q35 64 MiB using QEMU TCG with exact expected serial and debug-exit results. Because the PTE swap is intentionally stale, both experimental paths exit via the expected refusal code 35, never as an ordinary successful boot.

Run make test-cow-integrated-hw or make test using the pinned Hepta toolchain. The privileged exception entry, CR3/TLB invalidation, IRET, pointer ownership and single-core/quiescent ordering are explicitly NON-HIA boot-test scaffolding. This is not an atomic COW transaction, user Linux memory manager, SMP memory ordering proof or proof of hardware privilege support in HIA. Linux 7.3.4, its fixed source identity, the HIA toolchain lock, all 17 acceptance gates (HOLD) and the 422 syscall obligations remain unchanged.

# Experimental native quantum selection and actual two-task preemption

Parent #193 exact 0c96954f61d037ea766690a6b17fce20bf7044eb, original tests retained without modification. The new f13 checks live xAPIC, BSP, in-service periodic interrupt, nonzero even delivered tick, and aligned bounded state word. A native CAS admits only the next even generation (previous tick + 2); the selected task is the parity of tick/2. The slot and delivered tick are caller-provided, not an authority token.

New independent assembly bridge launches two actual CPL0 tasks with different stacks and 15 distinct GPR values each. It validates interrupted RIP, SS/RSP, CS/IF, progress on each departure, every task's GPR sentinels and stack canaries, and changes the actual IRET frame only after native f12 and f13 agree. Four switches at ticks 2,4,6,8, then return to supervisor at tick 9, stop and quiet-window check. A separate native f13 CAS deletion must prevent the first actual switch despite apparent success. PC/Q35 and both calibrated periods are planned; all original #193 cases remain independent. No result before execution. This is not native entry/return or native full context restore: assembly owns context bridge and initial stack frames. No FPU, user privilege, arbitrary tasks/cohorts, production scheduler, authority, or Linux ABI claim. Full 17 HOLD and 422 syscall obligations, production lock and both mains unchanged.

# Fixed two-CPU zero-before-publish physical page transfer (HOLD)

Parent #246 exact f358a053c70faff95057e354483730f0e7003939 includes the workflow path-filter syntax correction. This separate HIA experiment retains the original retirement/revoke/ACK/reuse test and all existing gates. The native page-transfer export has the same fixed two-CPU boot-arena and live CR3/FS/GS/APIC admission as the cohort export. After both actual generation-bound CPU ACKs and the original owner's reservation, it derives the other CPU as the next owner. It remaps the same physical page, fences and invalidates the local translation, then reads the actual PTE back before dereferencing the page. It atomically reads, clears and independently reads back each of exactly 512 aligned 64-bit words. Only after all 512 succeed does it publish the next owned generation. Failed remap/readback/scrub/publication after reservation returns partial status 10 and must fail-stop; this is not a multiword transaction or a general rollback protocol.

Actual desktop PC/Q35 16/16 with two real emulated CPUs and the exact #965 experimental compiler. The entire physical page begins with 512 nonzero old-data words. Both CPUs really warm the original mapping and observe a #PF after invalidation; both ACK bits precede transfer. Normal concurrent claim and separately ordered BSP/AP winners pass. The previous owner cannot retire even with the new generation. Only after the native publish and the observer's phase handshake does the new owner read every word, assert all 512 are zero, write its new markers, and successfully retire at generation 6. Five independent source mutations are detected on both machines: early reuse without peer ACK, remap CAS identity (partial state with PTE absent), scrub CAS identity (partial state with old content), skip scrub (actual publication with all old content intact), wrong new owner (actual wrong owner word). Two empty-PATH native builds and real linked text verified; original guard, IRQ, callback and owner object bytes preserved. No inherited tests removed.

This is cooperative fixed-layout software ownership and zero-on-transfer, not hardware confidentiality or prevention of arbitrary privileged reads. The new mapping is present during the scrub; a noncooperating CPU, hidden alias, DMA or concurrent page-table writer could violate the contract.

Parent #196 exact a6a0cf836f27058df15b0425b4ab0a2ef871fc89, independent 14/14 on PC/Q35. The prior source, fixture and workflow remain intact. New native HIA publishes a parked frame from a zero slot and consumes exactly the saved pointer to zero with locked CAS, fences, live BSP/xAPIC and periodic ISR admission, checked 160-byte extent inside the caller-supplied stack interval, nonoverlapping slot, and 8-byte alignment. It rejects duplicate publication and duplicate consumption. Boot initializes the active task's slot to zero. The original assembly observer still checks every saved register, per-task progress and chosen frame, then returns the frame to the already native raw gate. The new native operations replace the assembly writes of suspended frame pointers, and the resumed slot is empty. The original 14 scenarios are retained in the descendant experiment and two separate CAS-deletion controls are added on both machines (18 planned). No arbitrary stack authority, general task lifetime, rollback of multi-field handoff, native dispatcher, FPU, or full Linux claim.

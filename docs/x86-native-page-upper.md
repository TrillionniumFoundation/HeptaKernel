# Fixed upper page topology exclusion before physical page transfer

Experimental HOLD candidate based on #248 exact 6a0d3d92f0ef597eb99b9882a9c35d3995937baa. Retains the existing fixed low-leaf alias guard and adds native HIA inspection of the live upper hierarchy: unused PML4 and PDPT slots must be zero, PDPT[3] must point to the fixed APIC directory, all 511 higher PD0 huge leaves must be identity mappings (ignoring hardware A/D), and only the exact APIC aperture (plus A/D) may appear in PD3. This is a strict fixed-layout snapshot, not a concurrent-writer exclusion mechanism.

Independent PC/Q35 observers install actual physical aliases using PD0[1] huge, PDPT[1] with an independent huge-leaf directory, PML4[1] with independent PDPT and directory, and PD3[0] huge. Each reads both ends of the old physical page, expects native status 6 with unchanged original PTE and retiring ledger, and reads again. In each matching native guard-bypass mutant the original PTE is actually zero and the alias continues reading the old data. All 20 previous focused cases are retained; 16 new cases, local exact compiler 36/36. Initial r1 PDPT bypass failed (A/37) because it reused the very same PTE, so the independent alternate huge mapping was constructed in r2; r1 observer and report retained locally, no native code or expected result changed.

Independent CI reruns 580 inherited cases plus 36 new = 616. No general page authority, arbitrary address-space support, concurrent page-table mutation exclusion, noncooperative access isolation or full Linux acceptance is claimed. Original locks and budgets remain unchanged.

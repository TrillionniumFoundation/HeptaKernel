# Experimental frame rollback after refused owner publication

This is an isolated single-BSP, nonnested periodic-IRQ experiment, not Linux acceptance or a general multiword transaction. It preserves the production lock, all earlier test workflows, and all original acceptance obligations.

After the existing ready compensation test, the first IRQ performs an ordinary forward native frame handoff. The independent observer deliberately submits a stale generation to the native owner publisher and requires status 9. The new HIA guard independently derives the two slots from the same bounded task table, checks address extents, alignment, aliasing, active BSP periodic ISR, the exact parked outgoing frame and empty incoming slot, and compares the exact unchanged owner using identity CAS. A stale guard is rejected. This guard does not publish ownership.

With no other publisher or nested interrupt, the observer checks the unchanged ready word and invokes the existing native frame handoff in reverse with the two exact frame pointers and stack tops. It checks both restored slots and unchanged owner, rejects a replay of the pre-reversal guard, invokes the original native ready compensation (advancing rather than rewinding the generation), rejects its replay, and retries the normal dispatch. The original independent register, progress, canary, interrupt count, owner generation, and selection sequence checks remain. There are 13 IRQs and 12 switches in each positive scenario. The final ready generation increases by two relative to the parent experiment.

An independent stale reverse-consume test supplies a different, aligned frame pointer eight bytes below the exact outgoing frame (within the checked stack extent), requires status 9, and checks that the reverse park has itself been undone. It then fails closed without ready compensation or returning to a task. A separately compiled mutation replacing the reverse handoff's internal consume-rollback with park is detected. Additional controls omit the reverse invocation and ignore the live owner comparison. All ten parent negative controls are retained. The host tests remain the parent 98,219 compensation and 1,100 dispatch calls; they are not new concurrency evidence.

This demonstrates a bounded, caller-orchestrated recovery in the exact test state, not authority for arbitrary addresses, concurrent access, rollback after successful owner publication, general SMP, or a general scheduler. A failed recovery must stop rather than proceed to IRETQ. The original Linux acceptance remains HOLD.
